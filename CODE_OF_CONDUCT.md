# Code of Conduct

We want technical disagreement to be rigorous and respectful. Focus criticism on code, evidence, rule semantics, and tradeoffs rather than people. Harassment, discrimination, threats, doxxing, or deliberately hostile participation are not acceptable.

Maintainers may edit/remove abusive content or restrict participation to protect a productive project environment. When the repository is published, private conduct reports should use the maintainer contact path documented in the repository profile/security settings.
