# Roadmap

## v0.2 priorities

1. Calibrate rules against a broader curated real-world corpus and publish per-rule false-positive observations.
2. Add defensible import/environment diagnostics without executing user modules.
3. Improve static test-boundary mapping with import/call relationships rather than raw corpus signals.
4. Add release-history checks (version/changelog/integrity) only where repository publishing intent is observable.
5. Prototype a second language rule pack only after the Python contracts and contributor API stabilize.

Not planned: AI-authorship probability, cloud dashboard/account system, telemetry-by-default, architectural auto-deletion, or replacing specialist lint/type/security tools.
